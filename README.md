# Designforslag – Marianne Juvik Sæbø

Skisser til ny stil for nettsiden, til å velge mellom. Den ekte nettsiden ligger i `nordlyskonsert-main` og er ikke endret.

- `index.html` – oversikt over forslagene
- `index-a.html`, `index-b.html`, `index-c.html` – forslag 3 A, B og C (samme oppsett som i dag, ny stemning)
- `dagens.html` – forsiden slik den er i dag, vist som eget kort («Dagens design») på oversikten
- `eksklusiv-1.html` – eksklusivt forslag, kinematisk (i Adeles ånd)
- `eksklusiv-2.html` – eksklusivt forslag, klassisk eleganse (i Bocellis ånd)
- `eksklusiv-1b.html` – som eksklusiv 1, med scenebildet øverst
